# Documents de contexte

Ces quatre PDF servent de sources de travail pour préparer l’EPK de **Living Hair Art**. Ils ne constituent pas la version finale de l’EPK.

- `BRAIDSPLACE_Africa_Tour_2027_Dossier_Sponsors.pdf` : dossier sponsors, édition de travail du 30 octobre 2026.
- `BRAIDSPLACE_Living_Hair_Art_Johannesburg_April_2027.pdf` : proposition pour Johannesburg.
- `BRAIDSPLACE_Living_Hair_Art_Tanzania_April_2027.pdf` : proposition pour la Tanzanie.
- `CAPE TOWN INTERNATIONAL JAZZ FEST  (1).pdf` : présentation pour Cape Town.

Avant de reprendre un texte, une image ou un chiffre dans l’EPK, vérifier sa version actuelle avec Flo et les droits et crédits nécessaires.
